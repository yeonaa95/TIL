👉 오늘은 'Papago API 연동하기'에 서버를 만든 것에 외부 API (Papago)와 직접 연동해봤다. <br>

👉 어딘가의 서버에서 제공하는 API를 사용,테스트,소비하는 방법은 크게 세 가지가 있다. <br>

1. GUI형태로 작성(ex. API Client 툴)
   → 문서화, 협업 등에서 주로 활용

2. CLI형태로 작성(ex. curl같은 명령어 활용)
   → 리눅스 서버 컴퓨터에서 잠깐 테스트가 필요한 상황?
   리눅스 서버 컴퓨터는 기본이 CLI형태

3. 프로그래밍 코드로 작성(ex. XHR, fetch.. 등)
   → 실제 서비스 개발할 때 기능으로써 동작하려면 코드로 작성

사용자가 localhost:3000'/'로 요청했을 때 <br>
이제는 "Hello World"가 아니라, Papago 메인 페이지인 index.html을 응답하도록 구현

우리가 현실에서도 naver.com로 요청하면 네이버 메인페이지가 작성된 index.html이 응답됨

👉 HTTP 기반으로 서버에 요청을 보낼 때는 크게 9~10가지 방식이 있음

큰 틀에서는 본질적으로 2가지 방식이 있음

- GET : 조회 요청
- POST : 데이터를 추가/수정/삭제할 때

URL도 엔드포인트, 공개가 되는 API, 공개가 안 되는 API가 있다. <br>
API를 테스트 해볼 수 있는 것을 API 클라이언트라고 함.

👉 클라이언트가 서버한테 요청을 보내는 건 목적이 크게 2가지

1. 어떤 데이터를 조회하고 싶을 때(읽기 작업)

- ex. naver.com/index.html을 요청하는 것?
  → index.html이라는 파일을 읽고싶은 것 (보고싶은 것)

서버가 가진 어떤 데이터(html, png, mp4, JSON...)를 조회, 확인하는 요청

2. 어떤 데이터를 추가하거나 수정/삭제하고 싶을 때(쓰기 작업)

- ex. 게시물 작성
  → 서버의 데이터베이스에 새로운 게시글 데이터를 추가하는 요청 <br>
  작성한 게시물에 대한 데이터를 서버로 전송해야 함

ex. 로그인??을 하려면? ID/PW를 서버에 전송해야함
