> ### 1️⃣ Tailwind CSS 복습 및 심화
>
> **Tailwind CSS란?** <br>
> : Tailwind CSS는 유틸리티 우선(Utility-First) CSS 프레임워크.
>
> ```tsx
> // 기존 CSS 방식
> <button className="btn-primary">버튼</button>
> // + 별도 CSS 파일에 .btn-primary 스타일 정의 필요
>
> // Tailwind 방식
> <button className="px-4 py-2 bg-blue-600 text-white rounded-lg hover:bg-blue-700">
>   버튼
> </button>
> // CSS 파일 없이 클래스만으로 스타일링!
> ```
>
> **1. 자주 사용하는 유틸리티 클래스**
>
> | 카테고리     | 클래스 예시                         | 설명                    |
> | ------------ | ----------------------------------- | ----------------------- |
> | **여백**     | `p-4`, `px-6`, `m-2`, `mt-4`        | padding, margin         |
> | **크기**     | `w-full`, `h-10`, `max-w-md`        | width, height           |
> | **색상**     | `bg-blue-600`, `text-gray-900`      | 배경색, 글자색          |
> | **테두리**   | `border`, `rounded-lg`, `shadow`    | 테두리, 라운드, 그림자  |
> | **레이아웃** | `flex`, `grid`, `gap-4`             | Flexbox, Grid           |
> | **반응형**   | `md:flex`, `lg:grid-cols-3`         | 브레이크포인트별 스타일 |
> | **상태**     | `hover:bg-blue-700`, `focus:ring-2` | 호버, 포커스 등         |
>
> **2. 반응형 브레이크포인트** <br>
> : Tailwind의 반응형은 **모바일 우선(Mobile First)**
>
> ```
> sm:  640px 이상  (태블릿)
> md:  768px 이상  (태블릿 가로)
> lg:  1024px 이상 (노트북)
> xl:  1280px 이상 (데스크톱)
> 2xl: 1536px 이상 (대형 모니터)
>
> // 예시: 모바일에서 1열, md 이상에서 2열, lg 이상에서 3열
> <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
> ```

> ### 3️⃣ shadcn/ui 소개 및 설정
>
> **shadcn/ui란?** <br>
> : shadcn/ui는 **복사-붙여넣기 방식**의 UI 컴포넌트 라이브러리. <br>
>
> 📚 공식 문서: https://ui.shadcn.com
>
> 특징:
>
> - 라이브러리가 아니라 **컴포넌트 코드를 직접 복사**
> - Radix UI 기반으로 **접근성** 완벽 지원
> - Tailwind CSS로 **커스터마이징** 자유로움
> - 프로젝트에 필요한 컴포넌트만 선택 설치
>
> **1. shadcn/ui 초기화**
>
> ```bash
> npx shadcn@latest create
> or
> npm install -g shadcn@3.8.3
>
> # npm 서명 검증 문제발생시
> npm install -g pnpm
> pnpm dlx shadcn@latest create
>
> # 초기화
> pnpm dlx shadcn@latest init
> ```
>
> 1.1 대부분의 설정은 `components.json`에서 변경가능
>
> - 변경 가능한 설정
>
> | 설정             | 위치                    | 변경 가능 | 비고                      |
> | ---------------- | ----------------------- | --------- | ------------------------- |
> | **style**        | `"style"`               | O         | `default` 또는 `new-york` |
> | **baseColor**    | `tailwind.baseColor`    | O         | 새 컴포넌트 추가 시 적용  |
> | **cssVariables** | `tailwind.cssVariables` | O         | CSS 변수 사용 여부        |
> | **css 경로**     | `tailwind.css`          | O         | CSS 파일 경로             |
> | **aliases**      | `aliases.*`             | O         | import 경로 커스터마이징  |
> | **iconLibrary**  | `iconLibrary`           | O         | `lucide` 또는 다른 아이콘 |
>
> 1.2 주의사항
>
> - 이미 설치된 컴포넌트에는 적용 안 됨
> - `style`, `baseColor` 등을 변경해도 **기존 컴포넌트는 그대로** 유지됨
> - 변경된 설정은 **새로 추가하는 컴포넌트**에만 적용됨
> - 기존 컴포넌트에 새 설정 적용하려면:
>
> ```bash
> # 컴포넌트 덮어쓰기 (--overwrite 플래그)
> pnpm dlx shadcn@latest add button --overwrite
> ```
>
> - aliases 변경 시
>   : 경로 변경 후 기존 컴포넌트의 import 문도 수동으로 수정해야 함 <br>
>   예: `@/lib/utils` → `@/utils/shadcn_utils`
>
> **2. 필요한 컴포넌트 설치**
>
> ```bash
> # 버튼
> npx shadcn@latest add button
>
> # 입력 필드
> npx shadcn@latest add input
> npx shadcn@latest add textarea
> npx shadcn@latest add label
>
> # 선택 박스
> npx shadcn@latest add select
>
> # 카드
> npx shadcn@latest add card
>
> # 다이얼로그 (모달)
> npx shadcn@latest add dialog
> npx shadcn@latest add alert-dialog
>
> # 토스트 알림
> npx shadcn@latest add sonner
>
> # 스켈레톤 로딩
> npx shadcn@latest add skeleton
>
> # 드롭다운 메뉴
> npx shadcn@latest add dropdown-menu
>
> # 배지
> npx shadcn@latest add badge
>
> # 일괄설치
> pnpm dlx shadcn@latest add button card input dialog textarea label select alert-dialog sonner skeleton dropdown-menu badge
> ```
>
> **3. tsconfig.json 경로 별칭 설정**
> : shadcn/ui가 `@/` 경로 별칭을 사용하므로 설정이 필요
>
> - **파일: `tsconfig.json`**
>
> ```json
> {
>   "files": [],
>   "references": [
>     { "path": "./tsconfig.app.json" },
>     { "path": "./tsconfig.node.json" }
>   ],
>   "compilerOptions": {
>     "baseUrl": ".",
>     "paths": {
>       "@/*": ["./src/*"]
>     }
>   }
> }
> ```
>
> - **파일: `vite.config.ts`**
>
> ```tsx
> import { defineConfig } from "vite";
> import react from "@vitejs/plugin-react";
> import path from "path";
>
> export default defineConfig({
>   plugins: [react()],
>   resolve: {
>     alias: {
>       "@": path.resolve(__dirname, "./src"),
>     },
>   },
> });
> ```
>
> **4. cn 유틸리티 확인** <br>
> : shadcn/ui 초기화 시 src/lib/utils.ts가 자동 생성
>
> ```tsx
> // src/lib/utils.ts
> import { type ClassValue, clsx } from "clsx";
> import { twMerge } from "tailwind-merge";
>
> export function cn(...inputs: ClassValue[]) {
>   return twMerge(clsx(inputs));
> }
> ```
>
> **5. 설치 후 생성되는 파일**
>
> src/
> ├── components/
> │ └── ui/ # shadcn/ui 컴포넌트
> ├── utils/
> │ └── shadcn_utils.ts # cn() 유틸리티 함수
> └── index.css # CSS 변수 및 테마 설정
>
> components.json # shadcn/ui 설정 파일
>
> **6. 설치된 의존성**
>
> ```json
> {
>   "dependencies": {
>     "class-variance-authority": "^0.7.1",
>     "clsx": "^2.1.1",

>     "tailwind-merge": "^3.4.0"
>   },
>   "devDependencies": {
>     "tw-animate-css": "^1.4.0"
>   }
> }
> ```

> **1. index.css 수정됨** <br>
> : shadcn 설치하면서 추가된 css와 기존 css가 역할이 겹치는 것과 순서를 정리
>
> - 정리된 `index.css` 구조
>
> | 섹션                | 내용                                        |
> | ------------------- | ------------------------------------------- |
> | 1. Imports          | tailwindcss, tw-animate-css, shadcn         |
> | 2. Dark Mode        | `@custom-variant` 설정                      |
> | 3. CSS Variables    | `:root`와 `.dark` 통합 (shadcn + 커스텀)    |
> | 4. Theme Extension  | `@theme inline` (변수 참조)                 |
> | 5. Base Styles      | `@layer base` (전역 스타일, 스크롤바)       |
> | 6. Components       | `@layer components` (헤더, 버튼 등)         |
> | 7. Utilities        | `@layer utilities` (line-clamp, 애니메이션) |
> | 8. Custom Utilities | `@utility` (bg-main, text-default 등)       |
> | 9. Keyframes        | 애니메이션 정의                             |
>
> - CSS 경고는 `-webkit-line-clamp`에 대한 것으로, Tailwind가 빌드 시 자동으로 처리하므로 무시해도 됩니다.
