> ### 1️⃣ Query Key 설계
>
> **Query Key란?** <br>
> : Query Key는 캐시를 식별하는 고유 키예요. 배열 형태로 계층 구조를 표현합니다.
>
> ```ts
> // 예시
> ["posts"][("posts", "list")][("posts", "list", { category: "react" })][ // 모든 게시글 // 게시글 목록 // 특정 카테고리 목록
>   ("posts", "detail", "123")
> ]; // 특정 게시글 상세
> ```
>
> ```ts
> // HomePage.tsx
> const { data } = useQuery({
>   queryKey: ["posts", "list"],
>   queryFn: getPosts,
> });
>
> // 다른 파일에서 캐시 무효화
> queryClient.invalidateQueries({ queryKey: ["post", "list"] });
> //                                         ↑ 오타! "posts" → "post"
> ```
>
> **1. Query Key 상수 정의**
>
> ```ts
> export const queryKeys = {
>   posts: {
>     all: ["posts"] as const,
>     lists: () => [...queryKeys.posts.all, "list"] as const,
>     list: (filters) => [...queryKeys.posts.lists(), filters] as const,
>     details: () => [...queryKeys.posts.all, "detail"] as const,
>     detail: (id) => [...queryKeys.posts.details(), id] as const,
>   },
> };
>
> // 사용하는 곳
> useQuery({ queryKey: queryKeys.posts.lists() });
> queryClient.invalidateQueries({ queryKey: queryKeys.posts.lists() });
> ```
>
> ```
> posts
> ├── all         → ["posts"]
> ├── lists()     → ["posts", "list"]
> ├── list()      → ["posts", "list", { category: "react" }]
> ├── details()   → ["posts", "detail"]
> └── detail()    → ["posts", "detail", "abc123"]
> ```
>
> **1.1 list(filters) — 필터가 적용된 목록**
>
> ```ts
> list: (filters: { category?: Category | null }) =>
>     [...queryKeys.posts.lists(), filters] as const,
> // 예: ["posts", "list", { category: "react" }]
> ```
>
> ```ts
> // 전체 목록
> queryKeys.posts.list({});
> // → ["posts", "list", {}]
>
> // React 카테고리만
> queryKeys.posts.list({ category: "react" });
> // → ["posts", "list", { category: "react" }]
>
> // TypeScript 카테고리만
> queryKeys.posts.list({ category: "typescript" });
> // → ["posts", "list", { category: "typescript" }]
> ```
>
> **1.2 detail(id) — 특정 게시글 상세**
>
> ```ts
> detail: (id: string) => [...queryKeys.posts.details(), id] as const,
> // 예: ["posts", "detail", "abc123"]
> ```
>
> ```ts
> // abc123 게시글 상세
> queryKeys.posts.detail("abc123");
> // → ["posts", "detail", "abc123"]
>
> // xyz789 게시글 상세
> queryKeys.posts.detail("xyz789");
> // → ["posts", "detail", "xyz789"]
> ```
>
> **2. as const**
>
> ```ts
> // as const 없이
> ["posts", "list"][ // 타입: string[]
>   // as const 있으면
>   ("posts", "list")
> ] as const; // 타입: readonly ["posts", "list"]
> ```
>
> ```ts
> // string[]는 뭐든 들어갈 수 있음
> const arr: string[] = ["posts", "list"];
> arr.push("아무거나"); // OK
>
> // readonly tuple은 정확히 그 값만
> const arr = ["posts", "list"] as const;
> arr.push("아무거나"); // 에러!
> ```
>
> **2.1 키 계층 구조 시각화**
>
> ```
> queryKeys.posts.all
>         │
>         └── ["posts"]
>                 │
>         ┌───────┴───────┐
>         ▼               ▼
>     lists()          details()
>         │               │
> ["posts","list"]  ["posts","detail"]
>         │               │
>         ▼               ▼
>     list(filters)    detail(id)
>         │               │
> ["posts","list",  ["posts","detail",
>  {category}]        "abc123"]
> ```
>
> **3. 목록 조회할 때**
>
> ```ts
> // HomePage.tsx
> const { data } = useQuery({
>   queryKey: queryKeys.posts.list({ category: selectedCategory }),
>   queryFn: () => getPostsByCategory(selectedCategory),
> });
> ```
>
> **4. 상세 조회할 때**
>
> ```ts
> // PostDetailPage.tsx
> const { data } = useQuery({
>   queryKey: queryKeys.posts.detail(id),
>   queryFn: () => getPost(id),
> });
> ```
>
> **5. 캐시 무효화할 때**
>
> ```ts
> // 게시글 작성 후
> await createPost(data);
>
> // 목록만 무효화 (상세는 그대로)
> queryClient.invalidateQueries({ queryKey: queryKeys.posts.lists() });
>
> // 또는 모든 게시글 관련 캐시 무효화
> queryClient.invalidateQueries({ queryKey: queryKeys.posts.all });
> ```
>
> **5.1 무효화 범위**
>
> ```ts
> // 특정 게시글 상세만
> invalidateQueries({ queryKey: queryKeys.posts.detail("abc123") });
> // → ["posts", "detail", "abc123"]만 무효화
>
> // 모든 상세 쿼리
> invalidateQueries({ queryKey: queryKeys.posts.details() });
> // → ["posts", "detail", ...]로 시작하는 모든 쿼리
>
> // 모든 목록 쿼리
> invalidateQueries({ queryKey: queryKeys.posts.lists() });
> // → ["posts", "list", ...]로 시작하는 모든 쿼리
>
> // 게시글 관련 전체
> invalidateQueries({ queryKey: queryKeys.posts.all });
> // → ["posts", ...]로 시작하는 모든 쿼리
> ```

> ### 5️⃣ 무한 스크롤 구현
>
> **1. 무한 스크롤 훅 작성** <br>
> 파일: `src/hooks/queries/useInfinitePosts.ts` (새로 생성)
>
> ```tsx
> // src/hooks/queries/useInfinitePosts.ts
>
> /**
>  * 무한 스크롤 게시글 목록 조회 훅
>  *
>  * Day 1 요구사항: UX-003 (모바일 반응형 지원 - 무한 스크롤)
>  */
>
> import { useInfiniteQuery } from "@tanstack/react-query";
> import { getPostsWithOptions, type GetPostsResult } from "../../lib/posts";
> import { queryKeys } from "./keys";
> import type { Category } from "../../types";
>
> interface UseInfinitePostsOptions {
>   category?: Category | null;
>   pageSize?: number;
> }
>
> export function useInfinitePosts(options: UseInfinitePostsOptions = {}) {
>   const { category = null, pageSize = 10 } = options;
>
>   return useInfiniteQuery({
>     queryKey: queryKeys.posts.list({ category }),
>
>     queryFn: async ({ pageParam }) => {
>       return getPostsWithOptions({
>         category,
>         limitCount: pageSize,
>         lastDoc: pageParam,
>       });
>     },
>
>     // 첫 페이지는 커서 없이 시작
>     initialPageParam: null as GetPostsResult["lastDoc"],
>
>     // 다음 페이지 파라미터 결정
>     getNextPageParam: (lastPage) => {
>       return lastPage.hasMore ? lastPage.lastDoc : undefined;
>     },
>   });
> }
> ```

> ### 6️⃣ 캐싱 전략 이해
>
> **1. TanStack Query 캐싱 동작**
>
> ```
> ┌─────────────────────────────────────────────────────────────┐
> │  TanStack Query 캐싱 흐름                                    │
> ├─────────────────────────────────────────────────────────────┤
> │                                                             │
> │  1. 첫 요청                                                 │
> │     [컴포넌트] → [서버] → [캐시 저장] → [화면 표시]           │
> │                                                             │
> │  2. 같은 키로 재요청 (staleTime 내)                          │
> │     [컴포넌트] → [캐시에서 바로 반환] (서버 요청 안 함)        │
> │                                                             │
> │  3. staleTime 이후 재요청                                    │
> │     [컴포넌트] → [캐시 데이터 먼저 표시]                      │
> │                 → [백그라운드에서 서버 요청]                  │
> │                 → [새 데이터로 업데이트]                      │
> │                                                             │
> └─────────────────────────────────────────────────────────────┘
> ```
>
> **2. 캐시 무효화(Invalidation)**
> : 데이터가 변경되면 캐시를 무효화하여 새 데이터를 가져온다.
>
> ```ts
> // 게시글 생성 후
> queryClient.invalidateQueries({
>   queryKey: queryKeys.posts.lists(), // 목록 캐시 무효화
> });
>
> // 특정 게시글 수정 후
> queryClient.invalidateQueries({
>   queryKey: queryKeys.posts.detail(postId), // 해당 상세 캐시 무효화
> });
> ```
